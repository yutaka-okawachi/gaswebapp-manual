> 旧英訳機能の廃止・列移行の実施経緯と旧計画を保存した資料です。新担当者が以下の廃止・列移行・トリガー整理を繰り返す手順ではありません。記録当時の未実施・未確認と、現在の本番状態を区別してください。通常更新は[日常保守](DEVELOPER_GUIDE.md)へ進みます。

更新日：2026-10-20。ユーザーの方針により、英訳作業メニュー・再生成・確認画面の専用コードをローカルで廃止します。GASへの反映、実シートの列移行、実トリガーの削除、通常同期、commit、push、deploy、公開はこの変更には含めません。

## 2026-10-20の追記

親作業から実シートの列移行完了（312,248セル一致、GM2221保持、条件付き書式復旧済み）の報告を受けました。Notesの順序は `de,ja,en,source,ja_old,…` です。ユーザーのトリガー画面では対象プロジェクトが0件であることを親が確認済みです。他所有者まで0件とは扱いません。この委任側ではシート移行・トリガー削除を実行していません。全データ英語表示の現在の実装は [英語版ローカルプレビュー](ENGLISH_PREVIEW.md) を参照してください。以下の移行手順は実施前の計画として残します。

## ローカル変更

- `setup_credentials.js` の英訳作業メニューと `morphology_survey_review.js` の英訳用編集イベント4経路を削除します。行移動、同期案内、検索履歴グラフ、辞書候補メニュー、辞書の一括調査用 `onEdit` は保持します。
- 英訳再生成4ファイル、旧metadata関連6、英訳確認3、日英修正案関連7、旧対応付け整理1、Notes旧画面1の計22ファイルを `src/` から削除します。シートの候補・判断記録・内部台帳・行metadata・Script Propertiesは削除しません。
- `sheet_column_layout.js` は辞書・ダッシュボード用の共用見出し解決を残し、英訳専用の列定義・保存先処理を削除します。公開出力は見出し `ja` を読み、`ja_old`へ読み替えません。
- RW/RSの場面検索・頁検索・用語検索・候補表示を共通の空欄判定へ揃えます。null、未設定、空文字、空白だけのpageは除外し、数値0と文字列`0`は残します。GASの辞書実例分割も同じ結果であることをテストします。
- 専用コードの回帰テスト6本を削除し、共用列解決・公開出力・辞書編集・メニュー・ページ空欄判定を検証するテストへ置き換えます。

## トリガーの確認対象

以下はソースから確認した関数名です。実際の設置一覧、件数、所有者、現在の実行状態を確認した結果ではありません。

| 関数 | ソース上の用途 |
| --- | --- |
| `handleSourceEnglishEdit` | 直接英訳のインストール型編集イベント |
| `retrySourceEnglishQueue` | 直接英訳の時間主導キュー入口（現在は手動専用として停止） |
| `notesEnglishAutomaticTick` | 旧Notes英訳の時間主導入口 |
| `refreshEnglishReviewMetadataAutomatically` | 旧英訳元行照合の時間主導入口 |
| `handleJapaneseEnglishMobileEdit` | 旧モバイル確認のインストール型編集イベント |
| `processJapaneseEnglishMobileQueue` | 旧モバイル確認のキュー入口 |
| `englishRetranslationPoll_` | 旧再英訳受付のポーリング関数。設定があれば対象を照合 |

現コードにはトリガーの自動設置・削除経路はありません。`source_english_workflow.js` には `getProjectTriggers()` による設置確認がありましたが、列挙できるのは実行者が所有するトリガーです。別所有者のものも個別に確認が必要です。manifestには `script.scriptapp` スコープがなく、一覧確認のためだけに権限を追加しません。

将来、対象GASのエディタのトリガー画面で、所有者ごとに関数名・イベント種別・対象ブック・件数を記録し、英訳専用分だけを削除します。削除後は読戻しと実行履歴を確認します。検索履歴グラフ・辞書・その他の業務トリガーは対象外です。単純トリガー `onOpen` と辞書用 `onEdit` は保持します。このローカル変更で、実トリガーを削除したとは扱いません。

## 次の列構成とデータ方針

承認状態による公開フィルタは追加しません。保留も含めて日本語修正案を新 `ja` に昇格し、全行の旧日本語を `ja_old` に保全する方針です。英訳候補は `en` に改名します。GM2221の日本語・英訳はユーザーが入力済みであり、自動補完や旧訳への置換は行いません。

| タブ | 希望する主な列順 |
| --- | --- |
| RW / RS | `Oper, Aufzug, Szene, page, whom, whom_en, de, de_normalized, ja, en, ja_old, …` |
| GM | `de, de_normalized, ja, en, data, ja_old, …` |
| Notes | `de, ja, en, source, ja_old, …` |

`en`への改名は英語版の公開生成を追加する変更ではありません。現在の日本語exportは `en`・`whom_en`・`ja_old`・準備状態を公開データへ含めません。RW/RSのpage空欄行は全量データに残る場合もありますが、検索結果・用語候補・辞書実例からは除外します。

## 反映前の停止条件と次の手順

1. 外部writerと英訳専用トリガーを所有者ごとに確認し、実行中・送信中・保存結果未確認がないことを確認します。費用予約や未確定の受付を手で消して解消した扱いにはしません。
2. 候補・判断記録を含めたブックのバックアップ、各列のuserEnteredValue・数式・書式・メモ・入力規則・条件付き書式・保護・列幅・行metadataの控えを取得します。数式が参照している日本語列が本番列と旧版列のどちらを指すべきか確認します。
3. 読取時点の見出しと値を再照合してから、旧 `ja` を `ja_old`、修正案を `ja`、候補を `en` に改名し、列全体を移動します。行数・行順・識別子は維持します。値だけの貼付けで属性を失わないようにします。承認・保留・根拠欄も保持します。
4. 新 `ja` と移行前修正案、`ja_old` と移行前旧日本語、`en` と移行前候補を全行で照合します。GM2221のユーザー入力、page空欄、数式・書式・入力規則・行IDを読戻し確認します。
5. GAS編集版HEAD・固定公開版とローカルの再比較を行います。ローカルの `scripts/sync/gas-head.js` は、固定した22ファイルの名前・型・内容ハッシュ・対象プロジェクトハッシュ・基準commit・公開版1668を `english-retirement-20261020.json` と照合して、その廃止だけを許容します。一般の削除ガードは維持し、未知の追加削除、遠隔変更、部分削除、承認後の変更は停止します。読取専用の実HEAD/公開版比較でも条件一致を確認しました。実際の反映は未実施です。
6. 必要な同期検証・反映・公開は別の許可範囲です。今回 `sync-data` はCheckを含めて実行しません。ローカルテストの成功を通常同期の準備完了や本番確認済みとは扱いません。

当初の追跡対象ツリー内では旧プレビューを確認できませんでしたが、その後ユーザーのTemp内に旧540行版を発見しました。現在は共有HTML/CSSの全データ版へ置き換え済みです。日英統合同期の詳細は [日英統合同期](BILINGUAL_SYNC.md) を参照してください。
