# 英語版の作業ロードマップ

更新日：2026-10-12。次の通常sync-dataで編集版の機能を失わないよう、現HEADのコードをmainの同期元へローカル統合しました。今回の統合はGAS編集版・固定公開版へ反映していません。commit・push・通常sync-dataも未実施です。

## 現在の構成

`source_english_workflow.js` と `source_english_api.js` は、RW・RSの指示対象英訳を追加して読戻し確認済みの編集版HEADを基準にしています。共通のロック、行識別、API応答検証、費用予約は `notes_english_workflow.js` と `notes_english_api.js` に残します。Notes・GM・RW・RSの選択行だけを手動再生成する構成です。

メニューは `setup_credentials.js`、編集受付と既存の語形対応処理への接続は `morphology_survey_review.js`、指定行への移動は `sheet_row_navigation.js` です。いずれも現HEADと同じコードを保持します。RW・RS・GMのセル編集時の停止と、選択行だけの手動英訳を維持します。候補保存、本人の採用、本番への転記、公開を別工程として扱います。

旧ブランチを一括マージせず、稼働HEADのファイルを比較して統合しています。最初のローカル案では旧機能を外して安全停止させましたが、通常同期の準備には現HEADの入口を保持する方針を採りました。旧18モジュールの内容・依存・公開経路・回帰テストを確認し、そのまま保存しています。旧処理を無処理関数へ置き換えず、共有4ファイルもHEADの実装を保持します。実際に登録された全所有者のトリガーを列挙・変更したわけではありません。

## 保持するコードと生成物

調査時の編集版HEADは39ファイル、固定公開版は16ファイルでした。同期元を39ファイルにそろえ、次のように扱います。

| 分類 | 対象・扱い |
| --- | --- |
| 現機能の共有処理・入口 | `notes_english_workflow`、`notes_english_api`、`morphology_survey_review`、`setup_credentials`。HEADと同じコードを保持 |
| 旧機能の保全 | metadata関連6、旧英訳確認3、日英修正案関連7、旧対応付け整理1、旧Notes画面1の計18ファイル。将来の廃止候補だが、現HEADの関数・画面を削除せず保持 |
| 生成値 | `sync_build.js`。ソースから再生成し、コードを含まない生成ハッシュであることを同期前に検証 |

生成値を除く38ファイルはHEADと同じ内容です。旧18ファイルに実候補や秘密情報を追加しません。公開GETは従来の公開サイトへ案内し、管理APIは既存の許可された処理だけを受け付けます。旧確認画面を公開ページや公開APIの新しい入口として追加する変更ではありません。

通常同期はHEAD・公開版・同期元を照合し、未統合ファイルや競合があればcommit・push・GAS更新より前に停止します。安全確認に削除許可の迂回オプションはありません。準備完了にはMode Checkと実HEADの同期前判定の両方が必要です。準備済みでも公開実行済みを意味しません。

将来旧機能を廃止する場合には、必要な候補・判断記録の保管、全所有者のトリガー、外部writer等からの参照を別途確認します。今回は既存コードを保持するため、トリガーの削除・変更やシートのタブ削除を同期準備の条件にしません。

## 検証と残作業

- 手動処理、共有台帳、長文、予算、連打、原文・対応表の変更、本文と指示対象の部分保存、Nの同時編集を模擬データで検証します。
- 同期前の未統合検出、確認後のコード変更、読取り失敗、送信後の不一致、中断後の再開時の停止を非破壊テストで検証します。
- Notes・GM・RW・RSの候補列が、既存の公開JSON・辞書HTML・ダッシュボードへ混入しないことを検証します。英語版のページ・生成物は追加しません。
- 実シートの手動操作、実API応答、実行時間、全所有者のトリガーは未確認です。実データ・N列への書込みや有料APIでの検証は行っていません。

非公開の取得データと反映記録はローカルの `.sync-state/` で管理します。公開リポジトリには実候補を含めません。全対象の翻訳と本人確認が完了するまで英語版は非公開とし、noindexや隠しリンクを非公開の代用にしません。
