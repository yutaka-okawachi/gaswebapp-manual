# データ同期

実行前にユーザーの公開意図を確認する。実装だけの依頼では `-Mode Check` とプレビュー確認まで。

通常は `.\sync-data.ps1 -message "更新内容"` の一回実行で、組み立て・検証・必要なGAS更新・データ生成・GitHub公開・実体確認まで自動で進む。

GAS更新直後の反映遅延や一時的な通信失敗は自動再試行する。確認期限を超えた場合は、同じコマンドを再実行して反映済みデプロイを再利用する。

実行時はブラウザによる手動承認を挟まず、自動で最後まで進行する。進行状況はターミナル上にカラーで詳細に表示される。事前に画面を目視確認したい場合は `node scripts/preview-site.js --open` を使用する。

生成物を直接編集しない。ブランチの自動マージや変更の自動破棄を行わない。同期の正本は `manuals/DEVELOPER_GUIDE.md` 第2章。
