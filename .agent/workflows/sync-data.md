# データ同期

実行前にユーザーの公開意図を確認する。実装だけの依頼では `-Mode Check` とプレビューまで。

通常は `.\sync-data.ps1 -message "更新内容"` の一回実行で、組み立て・検証・必要なGAS更新・データ生成・プレビュー・GitHub公開・実体確認まで進む。

プレビュー内の公開ボタンはユーザーが画面を確認して押す。GASコードの更新が必要な場合はその更新前にも確認する。

生成物を直接編集しない。ブランチの自動マージや変更の自動破棄を行わない。同期の正本は `manuals/DEVELOPER_GUIDE.md` 第2章。
