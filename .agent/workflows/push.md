# Git変更の公開

サイト、GAS、データの変更は `sync-data.ps1` を使う。GASはGitHubへ直接書き込まず、ローカル同期だけを公開元とする。

```powershell
.\sync-data.ps1 -message "変更内容"
```

この一回の実行で、リモート先行の確認、許可対象ファイルだけのコミット、必要なGAS更新、データ生成、公開前プレビュー、GitHubへの送信、Pages実体確認まで行う。途中で停止した場合も同じコマンドで再開する。

マニュアルだけを例外的に手動公開する場合は、対象ファイル名を明示してステージし、差分を確認してからコミットする。`git add .` は使わない。リモートが先行している場合は、内容を確認してから取り込む。
